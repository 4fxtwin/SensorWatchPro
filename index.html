          Build

          1. Commit config to GitHub opens a pre-filled new file at . Click Commit changes.
          2. The Build firmware workflow compiles it against the pinned upstream revision. Open Actions.
          3. Download the artifact and unzip it to get firmware.uf2.
          4. Plug in the watch, double-tap its reset button, and copy firmware.uf2 to the WATCHBOOT drive. It reboots on its own.

          This config is too long for a pre-filled link. Use Copy config and paste it into a new file instead.

          Needs arm-none-eabi-gcc, make and git. The make target is the same one CI runs.
